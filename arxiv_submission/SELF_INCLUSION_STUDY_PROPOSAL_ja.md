# 対象別自己包含を調べる新実験案

**状態：2026年9月28日、著者・倫理審査で検討するための提案。** 新しい参加者、解析結果、事前登録、機関の承認はありません。2026年9月25日の改訂計画の中心的な提案を具体化したもので、同計画を確定指示や承認済み手順とは扱っていません。

## 研究の問い

同じ参加者の中で、「自分の一部」または「自分と切り離せない存在」と感じる程度が高い対象ほど、その対象についての言語連想の応答プロファイルは、本人の自己参照プロファイルに近いでしょうか。その関係は別の日にも再現するでしょうか。最初に検証するのは**対象別の自己包含**です。一時的な境界の薄れ、関係の親密さ、好意、向社会的行動は別の変数として扱います。

候補とする方向性は、自己包含の独立評定が高い対象ほど、その対象と自己とのプロファイル距離が小さいという**参加者内の負の関連**です。関連がない、逆方向になる、再現しない、単純な比較モデルを上回らない場合は、この測定法の提案に不利な結果です。関連が得られても、無意識の「真の境界」を読み取ったことや、新たな実体を測定したことにはなりません。

## 課題と評価項目の初期案

| 項目 | 確証的な収集前に決める初期案 |
| --- | --- |
| 対象 | 自己、事前に決めた規則で選ぶ4人、動物・自然など人以外の2対象。区分と親しみを記録し、第三者の身元を保護する。計7対象は実施可能性の初期案であり、普遍的な分類ではない。 |
| 刺激語 | 全対象に共通する約16語を、確証的収集前に選定・確認する。刺激一覧に「自己」という語が1つあるだけでは自己参照条件にならない。 |
| 教示 | 対象を短く意識したうえで、各語に対する**本人自身の連想**を答える。「その人になりきる」とは求めない。提示時間、文言、画面を条件間で揃える。 |
| 反復 | 別日の2回。7対象×16語で1日112試行、2日間で1人224試行を想定する。対象と語の順序を釣り合わせ、疲労や順序の影響を記録する。 |
| 独立評定 | 応答データとは別に、各対象の自己包含を直接尋ねる。親密さ、好意、重要性も比較用に別々に測る。「自分の一部」と「境界が薄い」を回答者が区別できるか確かめる。IOS/IOS11だけを後者の正解としない。 |
| 主要プロファイル | 参加者・日・対象ごとの「語×特徴」の応答ベクトルを事前に定義する。潜時だけの基準モデルから始め、皮膚電位や発話内容が追加価値を持つか検証する。欠測処理、標準化、特徴の重みを確証的な関連を見る前に固定する。 |
| 主要評価 | **自己以外**の各対象と自己のプロファイル距離が、対象別の独立評定と参加者内でどう関連するか。自己と自己の距離は自明にゼロなので除外する。別日のデータを保留して用いるか、2日を平均するか事前に決める。 |
| 信頼性 | 信号の再現性、対象距離・順位の安定性、評定と距離の関係の再現性を分けて調べる。旧データの潜時相関 `r=0.24` は、これらを推定した値ではない。 |
| 比較モデル | 対象区分、親しみ・親密さ、語彙や単純な潜時による説明と比較する。潜時の単純指標、潜時プロファイル、皮膚電位の追加、発話内容の追加、地図を使わないプロファイル距離を比較する。表示用の地図自体を心理測定値とは扱わない。 |

## 解析上の注意

独立した標本単位は**試行数ではなく参加者数**です。同じ人の複数対象の距離は共通の自己プロファイルを基準にするため、互いに依存します。対象の採用条件、無反応、アーティファクト、特徴の欠測、外れ値、変換、距離、別日の扱い、除外、共変量、不確実性の示し方、主要判定を事前に決めます。標準化や調整は学習データの中で行い、参加者単位で一般化を評価します。全体平均に加えて個人差を示します。見栄えのよい地図を選んで、その距離を後から主要評価項目にしません。

最初の約10名は、教示の理解、所要時間、信号の取得率、ばらつきを確かめるための実施可能性確認です。**妥当性を確証する標本ではありません。** 本試験の人数は、参加者内の依存、信頼性、脱落を考慮したシミュレーションまたは推定精度から決めます。確証的な結果を見る前に解析を固定し、研究計画に日時を残します。この提案書自体は事前登録ではありません。

刺激語・教示の版、対象の定義、割付と提示順序、イベント時刻、音声検出法、装置・ソフトウェアの版、元信号の単位と頻度、電極位置、校正、取得失敗、アーティファクト、除外理由を保存します。既存の倫理承認と同意が、新たな自己・他対象条件、評定、音声、生理記録を含むか確認し、必要なら**収集前**に変更承認または新たな承認を得ます。対象の実名と解析IDを分離し、音声、第三者名、繊細な連想内容のアクセス権と公開可能な派生データを定めます。
