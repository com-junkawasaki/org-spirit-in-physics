TensorFlow Projector 可視化ガイド

Spirit in Physics - 高次元データ可視化チュートリアル

📊 概要

このガイドでは、Spirit in Physics研究のデータをTensorFlow Projectorで可視化する方法を説明します。 高次元データをインタラクティブに探索し、感情・生理・単語埋め込みの関係性を視覚的に理解することができます。

🎯 学習目標:
  • TensorFlow Projectorの基本的な使い方
  • Spirit in Physicsデータの構造理解
  • 高次元データの次元削減と可視化
  • インタラクティブなデータ探索手法

📁 利用可能なデータセット

🧠 Word Embeddings (単語埋め込み)
感情関連単語の128次元ベクトル表現。単語間の意味的類似性を可視化します。
ベクトルファイル: word_embeddings_vectors.tsv
メタデータ: word_embeddings_metadata.tsv

可視化のヒント: 感情単語のクラスタリングを確認。類似する感情が近くに配置されるはずです。

💭 Emotion Patterns (感情パターン)
実験中の感情変化パターン。感情タイプと強度の時系列データをベクトル化。
ベクトルファイル: emotion_patterns_vectors.tsv
メタデータ: emotion_patterns_metadata.tsv

可視化のヒント: 感情タイプによるクラスタリングと、参加者間の感情パターンの違いを確認。

👥 Participant Features (参加者特徴)
各参加者の特徴ベクトル。Spirit確率、相関係数、データ品質を含む統合特徴。
ベクトルファイル: participant_features_vectors.tsv
メタデータ: participant_features_metadata.tsv

可視化のヒント: Spirit確率の高い参加者がどのようにクラスタリングされるか確認。

🫀 Physiological Time-series (生理時系列)
生理データの時系列ウィンドウ特徴。GSR、HRV、SCLの統計量ベクトル。
ベクトルファイル: physiological_timeseries_vectors.tsv
メタデータ: physiological_timeseries_metadata.tsv

可視化のヒント: 時間ウィンドウごとの生理パターンの変化を時系列で確認。

🚀 TensorFlow Projectorでの可視化手順

ステップ1: TensorFlow Projectorを開く

ブラウザで TensorFlow Projector を開いてください。

TensorFlow Projectorのメインインターフェース

ステップ2: データファイルをアップロード

「Load data from your computer」をクリックし、以下のファイルをアップロードしてください：

  1. Step 1: ベクトルファイル（例: word_embeddings_vectors.tsv）を選択
  2. Step 2: メタデータファイル（例: word_embeddings_metadata.tsv）を選択
# アップロードするファイルの例 tensorflow-projector-data/ ├── word_embeddings_vectors.tsv # 必須: ベクトルデータ ├── word_embeddings_metadata.tsv # オプション: メタデータ ├── emotion_patterns_vectors.tsv # 別のデータセット └── emotion_patterns_metadata.tsv

ステップ3: 次元削減手法を選択

データを2D/3Dで可視化するために、次元削減手法を選択してください：

  • UMAP: 非線形次元削減、局所構造を保持
  • t-SNE: 非線形次元削減、クラスタリングに適する
  • PCA: 線形次元削減、主成分分析
💡 推奨設定:
- 感情データの場合: t-SNE (perplexity: 30, iterations: 1000)
- 単語埋め込みの場合: UMAP (neighbors: 15, min distance: 0.1)
- 生理データの場合: PCA (主成分の分散を確認)

ステップ4: インタラクティブな探索

可視化されたデータをインタラクティブに探索してください：

  • ポイントクリック: 最近傍点を表示
  • ドラッグ選択: 領域内の点を選択
  • カラーリング: メタデータによる色付け
  • 検索: 正規表現によるポイント検索

インタラクティブなデータ探索インターフェース

ステップ5: 高度な機能を使用

より詳細な分析のために以下の機能を活用してください：

  • ブックマーク: 興味深いビューを保存
  • カスタム投影: 特定のベクトルによる投影
  • 時系列分析: 時間軸での変化を追跡

🔍 分析のヒントと解釈ガイド

Word Embeddingsの解釈

  • クラスタリング: 意味的に類似した感情単語が近くに配置される
  • 距離の意味: 近い単語ほど意味的・感情的に類似
  • 外れ値: 特殊な感情表現の単語は離れた位置に

Emotion Patternsの解釈

  • 感情タイプ別クラスタ: 同じ感情タイプのデータポイントが集まる
  • 強度グラデーション: 感情強度による色の濃淡を確認
  • 参加者差: 同じ感情でも参加者によって位置が異なる

Participant Featuresの解釈

  • Spirit確率: 高Spirit参加者は特定の領域に集まる
  • 相関係数: 生理・感情の関連性の強さが位置に反映
  • データ品質: 高品質データ参加者の分布パターン

Physiological Time-seriesの解釈

  • 時間的変化: 実験中の生理状態の遷移を追跡
  • ウィンドウパターン: 30秒ごとの生理特徴の変化
  • 参加者比較: 同じ時間帯での個人差

カスタム分析スクリプト

# Pythonでのカスタム分析例 import pandas as pd from sklearn.manifold import TSNE import plotly.express as px # データ読み込み vectors = pd.read_csv('word_embeddings_vectors.tsv', sep='\t', header=None) metadata = pd.read_csv('word_embeddings_metadata.tsv') # t-SNE次元削減 tsne = TSNE(n_components=2, perplexity=30, random_state=42) embeddings_2d = tsne.fit_transform(vectors) # インタラクティブ可視化 fig = px.scatter(embeddings_2d, x=0, y=1, text=metadata['word'], title="Word Embeddings t-SNE Visualization") fig.show()
