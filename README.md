# Spirit-in-Physics

このプロジェクトの完全なドキュメントは `PROJECT.jsonld` に統合されています。

詳細な情報については、`PROJECT.jsonld` を参照してください。

## クイックスタート

```bash
pnpm i
pnpm -F apps/researcher dev
```

ブラウザで 3D Force Timeline（`/3d-force-timeline`）へアクセス。

- `apps/researcher/src/components/TimelineVisualization.tsx`
